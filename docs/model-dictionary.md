# CFB_MODEL data dictionary

Generated by `make model-docs` from `sql/model/`; do not edit. The comments below are the ones stored in the database (`EXA_ALL_OBJECTS`, `EXA_ALL_COLUMNS`), which the deploy reads back and compares. Names are unquoted upper case: no quoting is ever needed.

Every table and view comment starts with its grain, "One row per ...". `Reads` lists the objects a view or table selects from, in schemas `CFB_MODEL`, `CFB_CORE` and `CFB_META` (the loader's plan views). The model never reads the virtual schema.

A *derived table* is a materialized view (decision [40]): the deploy fills it, and `CFB_INFRA.REFRESH_MODEL` rebuilds it after every load (refresh step 100, and the post-hook of `make backfill` and `make restore`), so its rows are current as of the last load. The other tables are curated seeds.

## CONFERENCE_CHAMPIONSHIP_GAME

*View, `sql/model/090_conference_championship_game.sql`.*

One row per detected conference championship game. CFBD does not mark these games: inside a season range of conference C in CONFERENCE_CHAMPIONSHIP, a game is detected when it is a regular-season game between two teams recorded in C on the game, flagged as a conference game, played no later than the season's POWER_CHAMPIONSHIP_WEEK, C's only such game in its week, and that week is C's last week with such a game up to that limit. So a conference without a championship game in the season, a game not flagged as a conference game after a found title game (Army-Navy in 2024) and a flagged game after the power conferences' championship week (Army-Navy in 2026) are never detected. Fallback: when this finds no game for C in the season, the same rule runs over every game between two teams of C, flagged as a conference game or not, with the power week counted the same way; CFBD does not flag the 2025 title games. A season without power-conference games (before 1998) has no fallback. The NOTES text is a cross-check only (MODEL_CHECKS: CONF_CHAMPIONSHIP_NOTES_MISMATCH, CONF_CHAMPIONSHIP_MISSING). Only FBS conferences are seeded; champions of conferences without a championship game come from the standings (Phase 4).

Reads: `CFB_CORE.GAMES`, `CFB_MODEL.CONFERENCE_TIER`, `CFB_MODEL.CONFERENCE_CHAMPIONSHIP`

| Column | Comment |
|---|---|
| `GAME_ID` | CFBD game id (GAME.GAME_ID) |
| `SEASON` | Season of the game |
| `CONFERENCE_NAME` | CFBD name of the conference whose championship game it is; both teams are recorded in it on the game |
| `WEEK` | Regular-season week of the game as CFBD labels it |
| `WEEK_SEQ` | Week sequence of the game (SEASON_WEEK.WEEK_SEQ); equal to WEEK, because championship games are regular-season games in CFBD |
| `START_AT` | Kickoff in UTC |
| `HOME_TEAM_ID` | CFBD team id of the home (first-listed) team |
| `HOME_TEAM` | CFBD school name of the home team |
| `AWAY_TEAM_ID` | CFBD team id of the away team |
| `AWAY_TEAM` | CFBD school name of the away team |
| `IS_COMPLETED` | TRUE once CFBD reports the game as completed |
| `WINNER_TEAM_ID` | Team id of the conference champion: the winner of the completed game; NULL while it is not played or after a tie |
| `NOTES` | CFBD notes of the game as stored, for example SEC Championship; a cross-check only, MODEL_CHECKS warns when notes and detection disagree |
| `POWER_CHAMPIONSHIP_WEEK` | The season's power-conference championship week: the last regular-season week in which a conference that CONFERENCE_TIER marks as power for the season plays a flagged conference game between two of its teams. For a game found by the fallback (CFBD does not flag the 2025 title games), it counts that conference's games flagged or not. Power conferences play no regular conference game after their title games, so once those are stored it is their week, and before that it is their last scheduled week. The rule looks only at weeks up to it; NULL in a season without such a game (before 1998), which has no limit |

## SEASON_WEEK

*Derived table, `sql/model/110_season_week.sql`.*

One row per season, season type and week that has games or a stored calendar week (regular and postseason only). WEEK_SEQ orders the regular season before the postseason and matches the (season, week, season type) arguments of REFRESH_WEEK. Dates come from the stored calendar when it has the week, else from the kickoffs. IS_DONE says whether the week is over, which decides the current as-of point. Materialized: rebuilt by CFB_INFRA.REFRESH_MODEL after every load, so it is current as of the last load or refresh.

Reads: `CFB_CORE.CALENDAR`, `CFB_CORE.GAMES`

| Column | Comment |
|---|---|
| `SEASON` | Season |
| `SEASON_TYPE` | regular or postseason; the only season types with weeks |
| `WEEK` | Week as CFBD labels it within the season type |
| `WEEK_SEQ` | Week sequence: regular week n = n, postseason week n = 100 + n, so the postseason follows the regular season and (season, week, season type) of REFRESH_WEEK maps to one row; 0 is reserved for the preseason point of the as-of helpers |
| `START_AT` | Start of the week in UTC: the stored calendar's start date when DATES_SOURCE is CALENDAR, else the first kickoff of the week's games |
