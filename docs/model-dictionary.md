## ERA

*Table, `sql/model/010_era.sql`.*

One row per era kind and season range, curated knowledge that CFBD does not provide: division structure, postseason format, champion selection and overtime rules. Replaced from git on every deploy.

| Column | Comment |
|---|---|
| `ERA_KIND` | Kind of era: DIVISION (governing divisions), POSTSEASON (bowls, BCS, playoff format), CHAMPION (how a national champion is decided) or OVERTIME (whether a game can end in a tie) |
| `ERA_CODE` | Code of the era, unique within its kind, for example BCS or I_A_I_AA |
| `FIRST_SEASON` | First season of the era |
| `LAST_SEASON` | Last season of the era; NULL while the era is open. Eras of one kind are contiguous |
| `CFP_TEAMS` | POSTSEASON eras only, else NULL: number of teams in the College Football Playoff, 0 before 2014, 4 in 2014-2023, 12 from 2024. The seeding rules of the 12-team playoff belong to Phase 4's selection configuration |
| `TIES_POSSIBLE` | OVERTIME eras only, else NULL: TRUE when a game can end in a tie (before 1996 at the FBS level; lower divisions adopted overtime in 1981) |
| `DESCRIPTION` | One sentence that says what the era was |

## CLASSIFICATION_LABEL

*Table, `sql/model/011_classification_label.sql`.*

One row per division era and CFBD classification code: the division name used at the time and whether the code is retroactive.

| Column | Comment |
|---|---|
| `DIVISION_ERA` | DIVISION era code from ERA: PRE_NCAA, NCAA_UNDIVIDED, UNIVERSITY_COLLEGE, DIVISION_I_II_III, I_A_I_AA or FBS_FCS |
| `CLASSIFICATION` | CFBD classification code: fbs, fcs, ii or iii |
| `LABEL` | Name of that classification in the division era, for example Division I-A |
| `IS_RETROACTIVE` | TRUE when the classification code did not exist in the era (fbs and fcs before 1978, ii and iii before 1973) |

## CONFERENCE_TIER

*Table, `sql/model/012_conference_tier.sql`.*

One row per conference name (NULL = every other FBS conference) and season range: its power tier in that range. Replaced from git on every deploy.

| Column | Comment |
|---|---|
| `CONFERENCE_NAME` | CFBD conference name; NULL means every other FBS conference, which takes the default tier of the era |
| `FIRST_SEASON` | First season of the range |
| `LAST_SEASON` | Last season of the range; NULL while open |
| `TIER` | Tier code: AQ (1998-2013 automatic qualifier), NON_AQ (1998-2013 other), P5 (2014-2023), G5 (2014-2023 other), P4 (2024 on), G6 (2024 on other) or INDEPENDENT |
| `IS_POWER_CONFERENCE` | TRUE for the tiers AQ, P5 and P4 |

## POLL

*Table, `sql/model/014_poll.sql`.*

One row per CFBD poll name: its code, the first season with data, the label lead in weeks and whether its final ranking comes before the postseason.

| Column | Comment |
|---|---|
| `POLL_NAME` | CFBD poll name as it appears in the rankings data |
| `POLL_CODE` | Short code: AP, COACHES, CFP, FCS_COACHES, D2_COACHES or D3_COACHES |
| `DATA_FROM_SEASON` | First season with CFBD data for the poll; NULL when CFBD does not state it |
| `LABEL_LEAD_WEEKS` | Weeks by which the poll label runs ahead of the games it reflects: an AP poll labeled week 10 is released after the games of week 9, so the lead is 1; the committee labels by the week it follows, lead 0. A lead that is too small only delays visibility; a lead that is too large would leak |
| `FINAL_BEFORE_POSTSEASON` | TRUE when the poll publishes its final ranking before the postseason (the committee selection ranking), so the ranking is visible at the last regular week even if CFBD labels it postseason |

## DATASET

*Table, `sql/model/015_dataset.sql`.*

One row per CFBD dataset: how it is stored or fetched, its declared seasons and gaps, and how its coverage is measured.

| Column | Comment |
|---|---|
| `DATASET_CODE` | Code of the dataset, for example GAMES, ELO or PLAYS |
| `LABEL_TEXT` | Name of the dataset as docs/cfbd-data-availability.md calls it |
| `ACCESS_CLASS` | How to get the data: STORED (in the demo load profile, read it from the model), ON_DEMAND (federated, query CFBD_VS selectively) or UNAVAILABLE (tier-gated on the project key) |
| `CFBD_ENDPOINT` | CFBD API endpoint that serves the dataset |
| `CORE_TABLE` | CFB_CORE mirror that stores the dataset; NULL unless ACCESS_CLASS is STORED |
| `VS_TABLE` | CFBD_VS virtual table for the dataset |
| `MODEL_OBJECT` | CFB_MODEL view that exposes a STORED dataset; NULL otherwise |
| `FIRST_SEASON` | First season CFBD declares data for; NULL when the dataset has no seasons or CFBD declares none |
| `LAST_SEASON` | Last season CFBD declares data for; NULL while the dataset is open |
| `GAP_SEASONS` | Comma-separated seasons without data inside the declared range, for example 1871; NULL when there are none |
| `COVERAGE_POPULATION` | Population that the measured coverage share is computed over: COMPLETED_FBS_GAMES, COMPLETED_FBS_VS_FBS_GAMES or FBS_TEAM_SEASONS; NULL when coverage is not measured |
| `COMPLETE_SHARE` | Measured share (0 to 1) from which a stored, final season counts as complete, DECIMAL(3,2); 0.95 unless calibrated |
| `NOTE` | Caveats from the CFBD data availability page |

## CLASSIFICATION_TRANSITION

*Table, `sql/model/016_classification_transition.sql`.*

One row per team (CFBD school name) and season range whose classification differs from the code CFBD records on its games. Empty unless Q6 says otherwise.

| Column | Comment |
|---|---|
| `TEAM_NAME` | CFBD school name of the team (TEAM.SCHOOL) |
| `FIRST_SEASON` | First season of the range (1978 or later) |
| `LAST_SEASON` | Last season of the range; ranges of one team do not overlap |
| `CLASSIFICATION` | Classification the team had in the range: fbs, fcs, ii or iii |
| `NOTE` | Why the row exists, for example the transition seasons of a move up to FBS |
